# BPMN 2.0 schemas

The OMG BPMN 2.0 XML schemas (`BPMN20.xsd`, `Semantic.xsd`, `BPMNDI.xsd`,
`DC.xsd`, `DI.xsd`), unmodified, as published at
<https://www.omg.org/spec/BPMN/20100501/>. These copies were taken from the
bpmn-moddle repository (`resources/bpmn/xsd`), which vendors the same files.

# DMN 1.3 schemas

`dmn/` holds the OMG DMN 1.3 XML schemas (`DMN13.xsd`, `DMNDI13.xsd`, and the
DMN versions of `DC.xsd` and `DI.xsd`), unmodified, as published at
<https://www.omg.org/spec/DMN/1.3/>. These copies were taken from the
dmn-moddle repository (`resources/dmn/xsd`), which vendors the same files.
